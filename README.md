# CSE 4256 – Programming in Python

This repository contains my **pre-class and in-class work** completed for  
**CSE 4256: Programming in Python** at **The Ohio State University College of Engineering**.

The purpose of this repository is to document my progress throughout the course and provide a collection of programming exercises, examples, and implementations developed during the semester.

---

## Course Description

CSE 4256 focuses on developing strong programming skills in Python through hands-on practice with language features, data structures, and algorithms.

Topics covered in this course include:

- Python control flow and expressions
- Literals and function invocation
- Package importing and module usage
- Built-in Python data structures
- Functional programming in Python
- Object-oriented programming
- Design patterns
- Graph theory data structures and algorithms
- Regular expressions
- Python libraries such as NumPy, NLTK, and NetworkX
